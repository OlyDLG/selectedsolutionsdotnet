## Section 2: The Graph of a Function

<a name="2.6" class="goback" onclick="winhisback()">__6__</a>) <i>True or False</i>&nbsp; A function can have more than one $y$&#8209;intercept.

__Sln__: $\box{\text{False}}$: if it has more than one $y$&#8209;intercept, then it intersects the $y$&#8209;axis&mdash;a vertical line&mdash;more than once, and thus it fails the vertical line test.&nbsp; (More formally, if it has more than one than $y$&#8209;intercept, then $x=0$ is being mapped to more than one value, which makes it not a function.)
<br><br>

__16__ and __22__) Determine whether the graph is that of a function by using the vertical-line test.&nbsp; If it is, use the graph to find: __a__) the domain and range; __b__) the intercepts, if any; and __c__) any symmetry with respect to the $x$&#8209;axis, the $y$&#8209;axis, or the origin.

<a name="2.16" class="goback" onclick="winhisback()">__16__</a>) 
<div class="qwimg"><img src="./Graphs/SullivanC3S2P16.png"></div>

__Sln__: Any vertical line with equation $x=a, -2 \lt a \lt 2$ intersects the graph in more than one point&mdash;one below the $x$-axis, one above, so $\box{\text{not a function}.}~$ (Note that even though this is not a function, the intercepts and symmetries are still well-defined: the $x$-intercepts are $(\pm2,0)$, the $y$-intercepts are $(0,\pm2)$, and it is symmetric with respect to the origin and both axes.)

<a name="2.26" class="goback" onclick="winhisback()">__26__</a>) 
Given $f(x) = \Frac{x^2 + 2}{x + 4}$: __a__) Is $\left(1,\Frac35\right)$ on the graph of $f$? __b__) What is $f(0)$ and what is this point on the graph? __c__) Find $x$ such that $f(x) = \Frac12$ and state which point(s) this is (or these are) on the graph of $f$. __d__) What is the domain of $f$? __e__ & __f__) List the $x$ and $y$-intercepts (if any).

__Sln__: __a__) A point $(x,y)$ is on the graph of $y=f(x)$ if $(x,y)$ makes the equation $y=f(x)$ a true statement; since $f(1) = \Frac{1^2 + 2}{1 + 4} = \Frac35, \left(1,\Frac35\right)~\box{\text{is}}$ on the graph of $f.$ 
<br>
 
__b__) $f(0) = \Frac{0^2 + 2}{0 + 4} = \Frac24 = \box{\Frac12}$, and thus the corresponding point on the graph is $\box{\left(0,\Frac12\right)}.$ 
<br>

__c__) We need $x$ such that $\displaystyle \frac{x^2 + 2}{x + 4} = \frac12$ and we’ve already found one such, $\box{x=0}$; to find any others, multiply through by $2(x+4)$ to yield $2x^2+4=x+4 \implies 2x^2-x = 0 = x(2x-1) = 0 \implies 2x-1=0 \implies \box{x=\frac12}$ (check: $\Frac{(1/2)^2+2}{1/2 + 4} = \Frac{9/4}{9/2}=\Frac12~\checkmark$), which means the points $\box{\left(0,\frac12\right)\text{ and }\left(\frac12,\frac12\right)}$ are on the graph of $f.$ 
<br>

__d__) The domain is all real numbers ___except___ any that make $f$ undefined; in this case, the only thing that can make $f$ undefined is division by zero, i.e., if $x+4 = 0 \implies x=-4$, so this is the point we must exclude from the domain; thus the domian is $\boxed{\left\{x\in\mathbb{R}: x\ne -4\right\}.}$
<br>

__e__ & __f__) The $y$-intercept happens when $x=0$, and we’ve already found that $y$ value, so the $y$-intercept is $\boxed{\left(0,\frac12\right)}$; the $x$-intercepts happen where $y=0$, so we must solve $\displaystyle \frac{x^2 + 2}{x + 4} = 0 \implies x^2+2=0$ which has no real solution, so the graph of this $f$ has $\boxed{\text{no }x\text{-intercepts.}}$
<br><br>

<a name="2.34" class="goback" onclick="winhisback()">__34__</a>) 
<b>Effect of Elevation on Weight</b> If an object weighs $m$ pounds at sea level, then its weight $W$ (in pounds) at a height of$h$ miles above sea level is given approximately by: 
$$W(h) = m\left(\frac{4000}{4000 + h}\right)^2$$

__Sln__: Amy’s altitude is given in feet, whereas in $W(h), h$ must be in miles, so we must first convert $14110\cancel{\text{ ft}} \times \Frac{1\text{ mile}}{5280 \cancel{\text{ ft}}} = \Frac{1411}{528} \doteq 2.672\text{ mi}$; now we simply evaluate $W\left(\Frac{1411}{528}\right) = 120\left(\Frac{4000}{4000+\Frac{1411}{528}}\right)^2 \doteq 120\left(\Frac{4000}{4000+2.672}\right)^2 \doteq 120(0.999332359)^2 \doteq 120(0.998665164) = \box{119.84\text{ lbs}}$
<br>

__b__) Use a graphing utility to graph the function $W = W(h)$; use $m = 120$ pounds.

__Sln__: <img src="./Graphs/SullivanC3S2P34b.png">
<br>

__c__) Left to the reader.
<br>

__d__ & __e__) At what height will Amy weigh 119.95 pounds?&nbsp; Does your answer seem reasonable? Explain.

__Sln__: We need to solve $119.95 = 120\left(\Frac{4000}{4000+h}\right)^2$ for $h$; begin by dividing through by $120$ to obtain $\Frac{119.95}{120} = \Frac{23.99}{24} = \left(\Frac{4000}{4000+h}\right)^2$; next, take the square-root of both sides: $\sqrt{\Frac{23.99}{24}} = \Frac{4000}{4000+h}$, and then reciprocate both sides: $\sqrt{\Frac{24}{23.99}} = \Frac{4000+h}{4000} = 1 + \Frac h{4000}$; finally, subtract $1$ from both sides: $\sqrt{\Frac{24}{23.99}} - 1 = \Frac h{4000}$, and multiply by 4000: $$\box{h = 4000\left(\sqrt{\frac{24}{23.99}}-1\right) \doteq 0.834\text{ mi}}$$
The graph in Part __b__ tells us that weight goes down with increasing altitude; since 2.672 mi is greater than 0.834 mi, we should expect her decrease in weight to be not as great at the lower altitude, so $\box{\text{yes}}$, this answer seems reasonable.

<a name="2.38" class="goback" onclick="winhisback()">__38__</a>) 
Is a graph that consists of a single point the graph of a function? Can you write the equation of such a function?

__Sln__: Yes: if the point has coordinates $(x,y)$, then $f$ is the function whose domain is the <i>singleton</i> set $\{x\}$; whose range is the singleton set $\{y\}$; and whose formula&mdash;given this domain and range&mdash;is simply $y=f(x).$
<br><br>

<a name="2.46" class="goback" onclick="winhisback()">__46__</a>) 
Is there a function whose graph is symmetric with respect to the $x$&#8209;axis? Explain.

__Sln__: No: in order for a graph to be symmetric wrt the $x$&#8209;axis, for each $x$ value mapped to a given $y$ value, that same $x$ value must also be mapped to $-y,$ which means one $x$ value is getting mapped to more than one $y$ value.&nbsp; This would violate the requirement that, for a relation to be a function, each domain value must be mapped to not more than one range value, so a graph symmetric wrt the $x$&#8209;axis (and we have already seen such a graph in Problem 16 above) cannot be the graph of a function.
<br><br>

__Geometry__ A wire 10 meters long is to be cut into two pieces: one piece will be shaped as an equilateral triangle, and the other piece will be shaped as a circle.&nbsp; __a__) Express the total area $A$ enclosed by the pieces of wire as a function of the length $x$ of a side of the equilateral triangle; __b__) what is the domain of $A(x)$? __c__) Graph $A = A(x)$; for what value of $x$ is $A$ smallest?

__Sln__: Here is a diagram of the situation:

<div class="feimg"><img  src="./Graphs/SullivanC3S6P12.png"></div>

__a__) The required area is the sum of the area of the triangle, $\Frac{\sqrt3}4 x^2,$ and the area of the circle, $\pi r^2$; $r$ is determined using the fact that the circumference of a circle $C = 2\pi r \implies r = \Frac C{2\pi},$ and after three lengths of $x$ meters are used for the triangle, $10 - 3x$ meters are left for the circumference of the circle, so $r = \Frac{10-3x}{2\pi}.~$ Thus $$A(x) = \frac{\sqrt3}4 x^2 + \pi\left(\frac{10-3x}{2\pi}\right)^2 = \box{\frac{\pi\sqrt3 x^2 + 100-60x+9x^2}{4\pi} = \frac{(9+\pi\sqrt3)x^2 - 60x + 100}{4\pi}.}$$

__b__) As a purely abstract mathematical function, $A(x)$ is a polynomial, so the domain ___would___ be all real numbers; however, $x$ represents a length and thus can’t be less than zero, where $x=0$ corresponds to using the whole 10 meters of wire to make the circle; the other extreme is to use the whole 10 meters for the triangle, meaning $x \le \Frac{10}3.~$ So, depending on whether one interprets the instructions as ___must___ make both figures or ___may___ make both figures, the domain is either $\box{0 \lt  x \lt \frac{10}3\text{ or }0 \le  x \le \frac{10}3.}$

__Constructing an Open Box__ An open box with a square base is required to have a volume of 10 cubic feet: __a__) express the amount $A$ of material used to make such a box as a function of the length $x$ of a side of the squarebase; __b__) how much material is required for a base 1 foot by 1 foot; __c__) how much material is required for a base 2 feet by2 feet? __d__) use a graphing utility to graph $A = A(x)$; for what value of $x$ is $A$ smallest?

__Sln__: (Even though we consider it an important part of solving this problem, we leave drawing a picture of the situation to the reader.)

__a__) The volume $V$ of a box with a square base of edge length $x$ is $V = x^2h$ where $h$ is the height of the box, measured in the same units as the base edge length; given that $V=10,$ $h(x) = \Frac{10}{x^2}.~$ The box being open doesn’t affect the volume, but it does affect the area of material needed: we don’t need material for, presumably, the &quot;top,&quot; i.e., the face opposite its square bottom, so the area of material required is $A(x) = A_{\text{base}} + 4A_{\text{1 side}} = x^2 + 4xh =$ 
$$\box{x^2 + \frac{40}{x^2}.}$$
