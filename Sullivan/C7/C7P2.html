Preface

In tutoring trigonometry (all math really, but especially trigonometry) I am often asked something like "How do you remember all these formulas/identities?"  I always answer: "I don’t, I remember where to look them up" (which, in 2026, is ridiculously easy to do on the internet: just type "trig identities" into any browser and the default search engine will, in a matter of microseconds—indeed, before you even finish typing it in!—return umpteen lists of trig identities).  However, remembering them, especially when you’re just learning them, isn’t really the issue; the issue is proper use of them: the whole point of the trig identities, etc., is to reduce complicated‑looking problems to simpler problems, in a—quite literally—formulaic way.  The issue is how to use the formulas to "plug-and-chug," and a big stumbling block toward that goal is recognizing which formulas/identities are applicable in a particular situation.  This is exacerbated by the plethora of new formulas being thrown at you in rapid succession.

The strategy I recommend for dealing with this problem, as tedious as it sounds, is this: at the top of each page of work, begin by re‑copying all the formulas/identities you are responsible for learning in that lesson (at the very least: the more you write out, the more you will retain what you’ve taken the time to write out, so by all means, write out identities from earlier lessons as well, especially if you find that you’re still struggling with recognizing them in problems you’re working on; for what it’s worth here, I also emphasize this strategy when learning the properties of exponents and logarithmic identities—basically, any situation in which you’re being required to learn a lot of new synoptic information in a short period of time).  To set the example and make abundantly clear what I mean, I will begin each section below with a re‑statement of the formulas/identities being "drilled" in that section (as well as re‑statement of the specific formulas/identities being used in each particular exercise).  By doing so, I hope to drive home to the student that the way to "memorize" this material is by written repetition (even if it sometimes seems excessive).

The Unit Circle:

Domain and range of the trig functions:

sin \(\mathbb{R}\) (all real numbers*) \([-1,1]\) (the closed interval from \(-1\) to \(1\), inclusive)
cos \(\mathbb{R}\) \([-1,1]\)
tan \(\mathbb{R}\) except odd multiples of \(\displaystyle\frac{\pi}2\), expressed \(\mathbb{R}\backslash \displaystyle \{(2k+1)\frac{\pi}2, k\in \mathbb{Z}\text{, i.e., } k \text{ any integer}\}\)

cot \(\mathbb{R}\) except integer multiples of \(\pi\), expressed \(\mathbb{R}\backslash \{k\pi, k\in \mathbb{Z}\}\)

Periodicity: The unit circle definitions of the trig functions should make it clear why sin, cos, sec, and csc take on their same values every change of \(\pm2\pi\) in their argument, and tan and cot do so every change of \(\pm\pi\); we say that sin, cos, sec, and csc are all periodic with period (or have periodicity of) \(2\pi\), tan and cot have periodicity \(\pi\); as identities: for any integer \(k\) and any real* number \(x\), \(\sin(x+2k\pi) = \sin x;\) \(\cos(x+2k\pi) = \cos x;\) \(\sec(x+2k\pi) = \sec x;\) \(\csc(x+2k\pi) = \csc x;\) \(\tan(x+k\pi) = \tan x;\) and \(\cot(x+k\pi) = \cot x.~\) (Note: these are not the only places where trig functions repeat their values—for example, \(\sin 0 = \sin\pi = 0\)—but they are "guaranteed" to repeat their values at these increments: \(|x-y| = 2k\pi, k \in \mathbb{Z}\) is a sufficient condition for \(\sin x = \sin y\), for example, but not a necessary condition.)  In general, \(f(x)\) is said to be periodic with (fundamental) period \(p\) (or have periodicity \(p\)) if \(p\) is the smallest number such that \(f(x+p) = f(x)\) for all \(x\) (for which \(f\) is well-defined; it is a theorem that if \(f(x+p) = f(x)\) for all \(x\) (in the domain of \(f\)), then for any integer \(k, f(x+kp) = f(x)\), again as long as \(x+kp\) is in the domain of \(f\)).

Even/odd-ness: cos and sec are even functions, i.e., for all \(x\) (in their domians), \(\cos(-x) = \cos x; \sec(-x) = \sec x\); sin, tan, csc, and cot are odd functions: \(\sin(-x) = -\sin x; \tan(-x) = -\tan x; \csc(-x) = -\csc x;\) and \(\cot(-x) = -\cot x\) for all \(x\) (in their respective domains).

* Actually, the sine and cosine functions are well‑defined and periodic with period \(2\pi\) for all complex numbers, but this is "beyond the scope of this course."

Solved Problems

10 and 14) The point \(P\) on the unit circle that corresponds to a real number \(t\) is given. Find \(\sin t, \cos t, \tan t, \csc t, \sec t, \text{ and } \cot t\).

5.10) \(\left(-\Frac{\sqrt3}2, -\Frac12\right)\)

Sln: Typos exist, so when the instructions specify something like The [given] point \(P\) [is] on the unit circle, I like to verify that claim (here it matters because if the point isn’t actually on the unit circle—like problems soon to come—then the solution is less immediate): \(\sqrt{\left(-\Frac{\sqrt3}2\right)^2 + \left(-\Frac12\right)^2} = \sqrt{\Frac34 + \Frac14} = 1~\chec.~\) Having confirmed that the point is on the unit circle, \(\cos t\) and \(\sin t\) are simply the \(x\)‑ and \(y\)‑coordinate of the point, respectively: \(\box{\cos t = -\frac{\sqrt3}2,~\sin t = -\frac12}\).  To get the rest, use the ratio and reciprocal identities: \(\tan t = \Frac{\sin t}{\cos t} = \Frac{-1/2}{-\sqrt3/2} = \box{\frac1{\sqrt3} = \frac{\sqrt3}3}\), \(\cot t = 1/\tan t = \box{\sqrt3}\), \(\sec t = 1/\cos t = 1/(-\sqrt3 /2) = \box{-\frac2{\sqrt3} = -\frac{2\sqrt3}3}\), \(\csc t = 1/\sin t = \box{-2}.\)  Notes: 1) a "check"—left to the reader—is to verify the identities \(\tan^2 t + 1 = \sec^2 t\) and \(\cot^2 t + 1 = \csc^2 t\) using the values obtained for those functions; 2) just as you eventually started preferring "improper" fractions to "mixed numbers," you’ll eventually no longer be required to rationalize denominators, which is why I’ve boxed both forms above.

5.14) \(\left(-\Frac{\sqrt5}5, \Frac{2\sqrt5}5\right)\)

Sln: We assume that this point is indeed on the unit circle, leaving the check for the reader (whom we encourage to try to do the check in their head; hint: you really only need to verify that \(x^2 + y^2 = 1\)).  Assuming that, we immediately have: \(\box{\cos t = -\frac{\sqrt5}5,~\sin t = \frac{2\sqrt5}5} \implies \tan t = \Frac{2\sqrt5/5}{-\sqrt5/5} = \box{-2} \implies \cot t = \box{-\frac12},~\sec t = 1/(-\sqrt5/5) = \box{-\sqrt5},~\csc t = 1/(2\sqrt5/5) = \box{\frac{\sqrt5}2}.\)
\(\cot^2 t + 1 = \csc^2 t\) check: \(\left(-\Frac12\right)^2 + 1 = \Frac54 = \left(\Frac{\sqrt5}2\right)^2~\chec\); the \(\tan^2 t + 1 = \sec^2 t\) check is left to the reader.

16 and 20) The point \(P\) on the circle \(x^2 + y^2 = r^2\) that is also on the terminal side of an angle \(\t\) in standard position is given. Find the value of each of all six trigonometric functions of \(\t\).

5.16) \((5, -12)\)

Sln: We don’t need to verify that the point lies on the described circle because any given point lies on the origin‑centered circle whose radius equals the distance of the point from the origin; but we do need to determine the distance, \(r\), of the point from the origin, because, given a point, \((x,y)\), the \(\cos\) of the the angle described \(\t\), is \(x/r\) and \(\sin\t = y/r\).  Now, \(r = \sqrt{x^2 + y^2} = \sqrt{5^2 + (-12)^2} = \sqrt{169} = 13\), so \(\box{\cos\t = \frac5{13},~\sin\t = -\frac{12}{13} \implies \tan\t = -\frac{12}5,~\cot\t = -\frac5{12},~\sec\t = \frac{13}5,~\csc\t = -\frac{13}{12}.}\)
\(\tan^2\t + 1 = \sec^2\t\) check: \(\left(-\Frac{12}5\right)^2 + 1 = \Frac{144}{25} + \Frac{25}{25} = \Frac{169}{25} = \left(\Frac{13}5\right)^2~\chec.\)

5.20) \((-3, 1)\)

Sln: \(r = \sqrt{(-3)^2 + 1^2} = \sqrt{10} \implies \box{\cos\t = -\frac{3}{\sqrt{10}},~\sin\t = \frac1{\sqrt{10}},~\tan\t = -\frac13,~\cot\t = -3,~\sec\t = -\frac{\sqrt{10}}3,~\csc\t = \sqrt{10}}.\)  (Denominator rationalization and checks are left to the reader, whom we encourage to attempt in your head.)

24, 28, 32, and 36) Use the fact that the trigonometric functions are periodic to find the exact value of each expression. Do not use a calculator.

5.24) \(\sin 390°\)

Sln: Working in degrees, the period of the \(\sin\) function is \(360\), which is a succinct way of saying that \(\sin(\t° + k\cdot 360°) = \sin\t°\) for any \(\t\) and any integer \(k\) (recall that the integers are \(\{0, \pm1, \pm2, \pm3,...\} = \mathbb{Z}\)).  Now, this is true for all \(\t\), but we’re only being required to memorize the trig function values for angles in the interval \([0,360)\)... precisely because the 360° periodicity of the \(\sin, \cos, \sec,\) and \(\csc\) functions means that we don’t have to memorize values for angles outside this interval: we can always express such angles as \(\t° + k\cdot 360°\) for some integer \(k\) and \(\t\) in that interval (proof?)  So we need to find \(\t \in [0,360)\) such that there exists an integer \(k\) such that \(\t + k\cdot 360 = 390\) (note that for this application we don’t really care what \(k\) is, just that it’s and integer).

In this case, the required values are not very difficult to "just see": clearly \(390 = 30 + 1\cdot 360\) so \(\sin 390° = \sin(30° + 360°) = \sin 30° = \box{\frac12}\).  But I’m going to do this "the hard way" as an illustration, because that’s the way that always works, i.e., when it’s not so easy to "just see" the required \(\t\); I’m also going to pretend like I’m using a calculator because I know that many students today are reliant on those.  Divide 390 by 360: you get 1.08333333. The integer part, 1, is the \(k\); to get \(\t\), subtract off the 1 and multiply what’s left by 360: you should get 30, the required \(\t°\). (Do not re‑enter 0.08333333 in by hand because your calculator stores more precision than it displays and if you don’t take advantage of that, you may end up with less precision than available, e.g., you may get 29.9 instead of the precise answer of 30.) We’re going to use this approach when we need to work in radians.

5.28) \(\sec 420°\)

Sln: Working in degrees, \(\sec\) has period \(360\) (because \(\cos\) has that period) so we need to figure out \(\t \in [0,360)\) such that \(420 = \t + k\cdot 360,~k\in\mathbb{Z}\).  We use our division method: \(420/360\) "\(=\)" \(1.16666667\) (remember, more digits are stored in memory); subracting \(1\) displays \(0.16666667\), and multiplying the display by 360 should give \(60 = \t\) in degrees. Thus \(\sec 420° = \sec(60° + 360°) = \sec 60° = 1/\cos 60° = 1/(1/2) = \box{2}.\)

5.32) \(\csc \Frac{9\pi}2\)

Sln: Working in radians, the period of \(\csc\) is \(2\pi\) (the same as \(\sin\) because \(\csc \t = 1/\sin\t\) so that whenever \(\sin\) repeats a value, so does \(1/\sin\)), i.e., \(\csc(\t + 2k\pi) = \csc \t\) for all \(\t\) and any \(k\in \mathbb{Z}\); but just as with degrees, we can always express any radian value as \(\t + 2k\pi\) with \(\t \in [0,2\pi)\) and some \(k\in\mathbb{Z}\) (proof?); and we do this the same way: by dividing by the period and seeing how much is left over.  However, when we’re working in radians, we want to see our results as multiples of \(\pi\), e.g., \(\Frac{\pi}4, \Frac{2\pi}3, \Frac{11\pi}6\), because that’s how the special angles whose trig function values we’re learning are expressed; and we need to remember that "what’s left" is a fraction of the whole period, \(2\pi\).  The way this looks is as follows:

\(\Frac{9\cancel{\pi}/2}{2\cancel{\pi}} = \Frac94 = 2 + \Frac14\), which is how many multiples of \(2\pi\) \(\Frac{9\pi}2\) is. In other words, \(\Frac{9\pi}2 = \t + 2k\pi\) with \(k=2\) and \(\t = \Frac14(2\pi) = \Frac{\pi}2 \in [0,2\pi)\) as required. Thus \(\csc \Frac{9\pi}2 = \csc\left(\Frac{\pi}2 + 2(2\pi)\right) = \csc\left(\Frac{\pi}2\right) = 1/\sin(\pi/2) = 1/1 = \box{1}\).

5.36) \(\sec \Frac{25\pi}6\)

Sln: \(\Frac{25\cancel{\pi}/6}{2\cancel{\pi}} = \Frac{25}{12} = 2 + \Frac1{12}\), i.e., \(\Frac{25\pi}6 = \Frac1{12}(2\pi) + 2(2\pi) = \Frac{\pi}6 + 2(2\pi)\) so \(\sec \Frac{25\pi}6 = \sec\Frac{\pi}6 = 1/\cos(\pi/6) = 1/(\sqrt3/2) = \box{\frac2{\sqrt3}}.\)

5.56) \(\tan\left(-\Frac{5\pi}6\right) - \cot\Frac{7\pi}2\)

5.64) For what numbers \(\t\) is \(f(\t) = \cot \t\) not defined?

Sln: \(\cot\t = \Frac{\cos\t}{\sin\t}\) so \(\cot\t\) is undefined for \(\t\) such that \(\sin\t = 0\). These are the standard position angles whose terminal side intersects the unit circle with a \(y\)‑coordinate of 0, which, in radians, is all integer multiples of \(\pi\); in set notation, \(\cot\t\) is undefined on \(\box{\{k\pi: k\in\mathbb{Z}\}}\).

5.86) If \(f(x) = \cot x\) and \(f(a) = -3\), find the exact value of: a) \(f(-a)\) and b) \(f(a) + f(a + \pi) + f(a + 4\pi)\)

5.92) Show that the range of the cotangent function is the set of all real numbers.

Pf: We need to show that given any real number \(x\), there exists a real number \(\t\) such that \(\cot\t = x\); we’re going to use co‑ordinate geometry (also known as Analytic Geometry). We divide the proof into three cases: \(x=0, x \gt 0, x \lt 0\).

Case \(x = 0\): \(\cot\Frac{\pi}2 = \Frac{\cos(\pi/2)}{\sin(\pi/2)} = \Frac01 = 0\) so \(0\) is in the range of \(\cot\).

Case \(x \gt 0\): Given an arbitrary real number \(x \gt 0\), consider the point \((x,1)\) on the line \(y=1\) in the Cartesian plane, as depicted below:

Each such \(x\) corresponds to a unique point on that line and thus determines a unique standard position angle, \(\t\), when connected to the origin by a segment, \(C\). Thus it also determines a unique triangle consisting of side \(C\) and sides \(A\) (connecting \((0,0)\) to \((x,0)\)) and \(B\) (connecting \((x,0)\) to \((x,1)\)). Furthermore, \(\Delta ABC\) is a right triangle (because side \(B\) is parallel to the \(y\)‑axis—proof?—which is perpendicular to the \(x\)‑axis by convention) which implies that \(\cot\t = \Frac x1 = x\). In other words, for each such \(x\), there exists some real number \(\t\) such that \(\cot\t = x\).

Case \(x \lt 0\): The argument is essentially identical, except that each \(x \lt 0\) determines a unique standard position angle with a measure greater than \(\pi/2\) so we must construct the right triangle on the other side of the \(y\)‑axis and use the signed length of \(B\)—which is still the \(x\)‑coordinate of the point, i.e., the given value of \(x\)—in the right triangle ratio definition of \(\cot.~~\blksq\)

5.98) Show that the period of \(f(\t) = \cot \t\) is \(\pi\).

Pf: We must show that \(\pi\) is the smallest positive real number such that \(\cot(\t + \pi) = \cot \t\) for all \(\t\) for which cot is well‑defined.  The proof consists of two parts: we show that \(\cot\) has period \(\pi\); and we show that \(\pi\) is the smallest positive number for which this is true.

Part 1: For all \(\t\) such that \(\sin(\t + \pi) \ne 0\), \(\cot(\t + \pi) = \displaystyle \frac{\cos(\t + \pi)}{\sin(\t + \pi)} = \frac{-\cos \t}{-\sin \t} = \frac{\cos \t}{\sin \t} = \cot \t\) (because if \(\sin(\t + \pi) \ne 0\), then \(\sin \t \ne 0\); proof?); this shows that \(\pi\) is a period of cot.

Part 2: We use the method suggested in the text as a hint for Problem 93: Suppose there exists \(p\) between 0 and \(\pi\), exclusive, i.e., \(0 \lt p \lt \pi,\) such that \(\cot(\t + p) = \cot \t\) for all \(\t\) for which it is well‑defined; then \(\cot p = \cot(0 + p) = \cot 0 = 0\), i.e., our assumption implies \(\cot p = 0\), and there is only one value between 0 and \(\pi\) for which this is true, namely \(\frac{\pi}2.~\) But, for example, \(\cot \frac{\pi}4 = 1\), whereas \(\cot(\frac{\pi}4 + \frac{\pi}2) = \cot \frac{3\pi}4 = -1\); in other words, we’ve found a value of \(\t\) such that \(\cot(\t + \frac{\pi}2) \ne \cot \t\), so \(p=\pi\) must be the smallest (positive) value for which \(\cot(\t+p) = \cot(\t)\) is always true.\(~~\blksq\)

Section 6: Graphs of Sine and Cosine

Formulas Section

Relationship between their (fundamental) graphs: starting with the cofunction identity \(\sin x = \cos\left(\displaystyle\frac{\pi}2-x\right)\), factoring \(-1\) from the argument of the cos function and using the fact that cos is an even function \(\displaystyle \implies \sin x = \cos\left[-1\left(x-\frac{\pi}2\right)\right] = \cos\left(x-\frac{\pi}2\right)\), so the (fundamental) graph of sin is the same as cos, horizontally shifted \(\displaystyle\frac{\pi}2\) units to the right, or, equivalently, the (fundamental) graph of cos is the same as sin, horizontally shifted \(\displaystyle\frac{\pi}2\) units to the left.

Amplitude and period: given \(y = f(x) = A\sin(\w x)\text{ or } = A\cos(\w x), \w \gt 0\) (if \(\w \lt 0\) begin the analysis by changing \(A\sin(\w x)\) to \(-A\sin(|\w| x)\), \(A\cos(\w x)\) to \(A\cos(|\w| x)\)): the amplitude of \(f\) is \(|A|\), which gives the maximum and minimum values (maxima and minima) attained by \(f\) and the factor (i.e., multiplier) by which the (fundamental) graph is vertically "stretched" (\(|A| \gt 1\)) or "compressed" (\(|A| \lt 1\)); and the (fundamental) period (see Section 5 above for the definition) of \(f\) is \(T = \displaystyle \frac{2\pi}{\w}\), which gives the distance between consecutive maxima (and minima), and twice the distance between consecutive zeros and between any maximum and the next minimum and vice‑versa (i.e., the distance between consecutive zeros, and between a maximum (resp. minimum) and the next minimum (resp. maximum) is half the period, \(\displaystyle \frac T2\)).  Conversely: given the amplitude, \(A\), the period, \(T\), and whether the function has a zero, or a maximum or minimum, at zero (or information from which these properties can be deduced, e.g., the maximum or minimum value, the minimum distance between these, and the value at zero), one can immediately write down \(\displaystyle f(x) = A\sin\left(\frac{2\pi}T x\right)\) (if \(f(0) = 0\)) or \(\displaystyle f(x) = \pm A\cos\left(\frac{2\pi}T x\right)\) (if \(f(0) = \pm A\)).

8.34) Given the following data about the tide in Sitka Sound, Alaska, USA, on July 25, 2009:
\(~~~\)Length of time between consecutive high tides: 12 hours, 25 minutes;
\(~~~\)Time of occurrence of a high tide: 2:37 AM (2.6167 hours after midnight);
\(~~~\)Time of occurrence of the following low tide: 9:12 AM (9.2 hours after midnight; we assume the 9:12 PM printed in our copy of the text is a typo);
\(~~~\)High tide height above mean lower low water level: 11.09 feet;
\(~~~\)Low tide height: -2.49 feet;
answer the following questions:
a) Approximately when will the next high tide occur?
b) Find a sinusoidal function of the form \(y = A\sin(\w x - \phi) + B\) that models the data.
c) Use the function found in part b) to estimate the water height at 6 PM (18 hours).

Sln: a) We are told that high tides occur 12 hours, 25 minutes apart, so if a high tide was recorded at 2:37 AM, the next one should occur at 2 + 12 = 14 hours + 37 + 25 = 1 hour, 2 minutes = 15 hours, 2 minutes, i.e., at \(\box{\text{3:02 PM}}\); however,

b) The thing about sinusoids is that not only are they periodic, they’re also symmetric around their maxima, minima and zeros: not only are maxima and minima separated by integer multiples of the period, the maxima and minima occur one half‑period away from each other, and both of those occur one‑quarter period away from central values.  On that basis, we would expect the low tide after the 2:37 AM high tide to occur at 2:37 + 6 hours, 12.5 minutes = 8:49.5 AM, not 9:12 AM: is the given information wrong?  Yes and no: it is "oversimplified."  Tides are only approximately periodic; in particular, the statement "the length of time between consecutive high tides is 12 hours and 25 minutes" is true as an average, but not precisely from one high tide to another (and the central value and amplitude of tides varies considerably, as any oyster farmer knows extremely well!)  But neither is it exactly true that the period is 2(9:12 - 2:37) = 2(6:35) = 13 hours, 10 minutes, as the actual given tide times would imply.  So what are we to do?

Well, the (real) purpose of this problem is not to teach us about the detailed physics of the tides, but to provide us with an exercise in formulating a sinusoid from "real world" numerical data.  So: let’s figure out a model for each of the two different periods and graph them on the same set of axes to visualize just how different they are.  (FWIW, this is my recommendation to students when I’m substituting for a teacher and an ambiguity in an assignment is discovered: I suggest that, time permitting, they solve the problem "both ways"—that way, one way or another, they’ve provided the desired answer, as well as showing that they can solve it given either interpretation of the problem.)

Either way, we only have one set of data to determine the amplitude and central value for the model, so we’ll calculate those first: \(A = [11.09 - (-2.49)]/2 = \box{6.79}\) feet and \(B = [11.09 + (-2.49)]/2 = \box{4.3}\) feet.  Next we calculate the two different periods and phase shifts.  For the 12 hour, 25 minute = 745 minute period (one period equals the interval between consecutive maxima, i.e., high tides), \(\box{\w = \frac{2\pi}{745}}\); because we’re asked to find a \(\sin\) function model (since we’re given the time of a maximum, it would be easier to calculate a \(\cos\) model, but alas, that’s not what we were asked for), the phase shift is found by finding \(\phi\) so that the argument of the \(\sin\) function in the model, \(\w t - \phi\), evaluated at the time of the known maximum, \(t=157\), equals the "first" argument at which \(\sin\) has a maximum, namely \(\Frac{\pi}2\)—in other words, we need to solve \(\Frac{2\pi}{745}(157) - \phi = \Frac{\pi}2 \implies \phi = \Frac{314\pi}{745}-\Frac{\pi}2 = \box{-\frac{117\pi}{1490}}\). Thus the model assuming a 745 minute period is: \[\box{H_{T=745}(t,\text{ in minutes}) = 6.79\sin\left(\frac{2\pi}{745}t + \frac{117\pi}{1490}\right) + 4.3\text{ feet}}\] Check: \(6.79\sin\left(\Frac{2\pi}{745}(157) + \Frac{117\pi}{1490}\right) + 4.3 = 6.79\sin\left(\Frac{(628+117)\pi}{1490}\right) + 4.3 = 6.79\sin(\pi/2)+4.3 = 11.09\text{ ft}~\chec\) \(6.79\sin\left(\Frac{2\pi}{745}(157 + 745) + \Frac{117\pi}{1490}\right) + 4.3 = 6.79\sin\left(\Frac{2\pi}{745}(157) + 2\pi + \Frac{117\pi}{1490}\right) + 4.3 = 11.09\text{ ft}~\chec\)
